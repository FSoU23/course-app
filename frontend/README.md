# Личная библиотека — книги, статусы чтения и заметки

Веб-приложение для учета личной библиотеки, отслеживания статусов чтения (запланировано, читаю, прочитано) и ведения личных заметок к произведениям.

## Информация о проекте
- **Автор:** [Каташинский А.В.]
- **Группа:** [24ПИ2]
- **Основной сценарий:** Просмотр коллекции книг, фильтрация по статусам чтения, добавление/редактирование карточек книг, сохранение личных заметок и оценок.

## Лабораторная работа № 3

Работают создание, редактирование, удаление с подтверждением и фильтр по статусу.
Одна форма `BookForm` использует отдельный черновик и проверяет название,
автора, дату и оценку (целое число 1–5 либо пусто). Список хранится в `App`,
страницы получают его и обработчики через props. После обновления страницы
изменения сбрасываются к демонстрационным данным; внутренние переходы их сохраняют.
Добавлен маршрут `/books/:id/edit`, весь интерфейс оформлен в нежно-розовых тонах.

Запуск: `npm ci`, затем `npm run dev`. Проверка: `npm run lint`, `npm run build`.
Готовая сборка: `npm run preview`.

## Лабораторная работа № 4

Жанр выбирается из `public/demo/genres.json`, который загружается реальным GET
по `/demo/genres.json`. Новые файлы: `src/types/genre.ts`, `src/services/genres.ts`,
`src/hooks/useGenres.ts`. Сервис проверяет HTTP-статус, JSON, структуру и уникальность id.
В книге хранится id жанра, а название берётся из того же сетевого справочника.

Форма показывает загрузку, ошибку и пустой результат, позволяет повторить запрос
без потери черновика и отменяет запрос при уходе. Сохранить книгу можно только
с существующим жанром после успешной загрузки. Остальной CRUD и временное
хранение в App сохранены. Дополнительные зависимости и ключи API не нужны.

Пошаговая проверка Network, Offline, пустого и повреждённого JSON находится
в [README проекта](../README.md#проверка-http-загрузки).
Объяснение новых файлов — в [памятке ЛР 4](../docs/lab4-defense.md).
