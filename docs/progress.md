## Лабораторная работа № 3: Формы и локальное состояние

Дата: 12.10.2026.

### Результат

- Общий список книг перенесён в `useState` компонента `App`; демонстрационный
  массив используется только для начальной копии данных.
- Добавлен `BookDraft = Omit<Book, 'id'>`. Создание использует `crypto.randomUUID`,
  обновление сохраняет id; операции используют функциональные обновления,
  spread, `map` и `filter`, не меняя исходные объекты.
- Общая управляемая форма `BookForm` обслуживает создание и редактирование
  всех восьми содержательных полей. Ввод хранится в отдельном черновике.
- Проверяются название (3–100 символов после trim), непустой автор,
  обязательная дата и необязательная целочисленная оценка 1–5. Пустая оценка
  становится `null`; ошибочный ввод не очищает форму и не изменяет список.
- Поля имеют подписи, подсказки и ошибки; при неуспешном сохранении фокус
  переходит к первому ошибочному полю. Кнопки имеют явный type.
- Создание открывает карточку новой книги. Редактирование использует
  `/books/:id/edit` и `key={book.id}`. Отмена не сохраняет черновик.
- Удаление требует подтверждения и возвращает к списку с заменой записи истории.
  Отсутствующий id обрабатывается и в подробностях, и при редактировании.
- Добавлен локальный фильтр по статусу со сбросом и счётчиком записей.
  Пустая коллекция и отсутствие совпадений показывают разные сообщения.
- В общем layout видно пояснение о хранении в памяти и сбросе после обновления.
- `index.css` и `App.css` обновлены: нежно-розовая палитра для всего сайта,
  адаптивные карточки и формы, видимый фокус, читаемые ошибки.
- Обновлены оба README; добавлена памятка `docs/lab3-defense.md`.
