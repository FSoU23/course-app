# Защита лабораторной работы № 2

## Демонстрация

Запустите приложение по README. Покажите пять книг на `/books`, затем b1 и b2:
у них разные авторы, статусы, оценки и заметки. Скопируйте адрес b2 в новую вкладку
и обновите страницу. Покажите `/books/new`, `/unknown`, `/books/missing` и возврат
к коллекции. Завершите демонстрацией успешной команды `npm run build`.
Для ссылки на коммит ЛР 2 используйте `git log -1 --oneline` после его сохранения.

## Ответы на вопросы методички

1. **Страница и компонент.** Страница соответствует маршруту, например BooksPage
   для `/books`. BookCard — повторяемая часть страницы, показывающая одну книгу.
2. **Props и тип.** BookCard получает `{ book: Book }` от BooksPage. Тип Book
   проверяет наличие полей и допустимые статусы/оценки во время разработки.
   Компонент читает props и не ищет книгу самостоятельно.
3. **key.** Стабильный `book.id` задан в map на BookCard. React сопоставляет элементы
   между отображениями по ключу. Индекс меняется при перестановке, случайный ключ
   создаёт новую идентичность. key не передаётся как обычный prop; id доступен в book.
4. **Router.** BrowserRouter связывает React с адресом и историей браузера.
   Routes выбирает подходящий Route; Route задаёт соответствие пути и компонента.
   Outlet отображает дочернюю страницу внутри общей оболочки AppLayout.
5. **id.** В `/books/b2` сегмент b2 попадает в параметр `:id`; useParams читает его.
   `books.find(item => item.id === id)` находит запись в общем массиве.
   После обновления адрес остаётся, массив загружается снова, поэтому карточка работает.
6. **Две ошибки.** `/unknown` не соответствует известным путям и попадает в `*`.
   `/books/missing` соответствует `/books/:id`, но find возвращает undefined.
   Проверка отсутствия книги выполняется до чтения её полей.
7. **ЛР 3.** На существующей странице создания появится форма с вводом полей,
   проверкой значений и реальным добавлением книги. Сейчас сохранения нет по заданию.

## Дополнительные детали

- Статический путь `/books/new` имеет приоритет перед параметром `/books/:id`.
- `Navigate replace` заменяет `/` в истории, чтобы назад не возвращал к перенаправлению.
- `NavLink end` выделяет коллекцию только на её точном адресе.
- `Link` и `NavLink` меняют страницу внутри SPA без загрузки нового HTML.
- Возврат из карточки ведёт явно на `/books`, даже если она открыта в новой вкладке.
- `rating: null` означает отсутствие оценки, а не нулевую оценку.
- Дата хранится как YYYY-MM-DD; строковый тип сам по себе не проверяет календарную дату.
- Поле id служебное; на странице показаны все восемь содержательных полей книги.
