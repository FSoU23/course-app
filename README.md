# Личная библиотека

Учебное приложение для учёта книг, статусов чтения и личных заметок.
Автор: Каташинский А.В., группа 24ПИ2.
Репозиторий: https://github.com/FSoU23/course-app

## Текущий этап: лабораторная работа № 2

Продолжен проект ЛР 1 (коммит `fc634a7`). Добавлены пять вымышленных книг,
список, подробности по URL, заглушка создания, общий layout и навигация.
Все книги, авторы и заметки демонстрационные. Данные находятся в одном
типизированном массиве `frontend/src/data/books.ts` и не сохраняются на сервер.
Формы создания, редактирования и удаления появятся в ЛР 3; HTTP и Supabase пока не подключены.

## Среда и запуск

Node.js 22.20.0 (зафиксирован в `.node-version`), npm 10.9.3.
React + TypeScript + Vite, React Router 7.18.4 (декларативный режим), CSS.
Точные версии зависимостей фиксирует `frontend/package-lock.json`.

Из корня проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).
Для остановки сервера нажмите Ctrl+C.

Из папки `frontend`:

```bash
npm run lint
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist`; preview обычно доступен на
http://localhost:4173. Используйте фактический порт из терминала.
При будущем размещении на хостинге потребуется возврат `index.html` для SPA-маршрутов.

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/` | Перенаправление на `/books` с заменой записи истории |
| `/books` | Коллекция из пяти книг |
| `/books/b1` … `/books/b5` | Подробности выбранной книги |
| `/books/new` | Заглушка создания с пояснением про ЛР 3 |
| `/books/missing` | Сообщение «Книга не найдена» |
| `/unknown` | Сообщение «Страница не найдена» |

## Структура

- `frontend/src/types/book.ts` — тип Book, статусы, оценка и русские подписи.
- `frontend/src/data/books.ts` — единый массив пяти демонстрационных книг.
- `frontend/src/components/BookCard.tsx` — карточка с типизированными props.
- `frontend/src/pages/` — список, подробности, создание и неизвестный адрес.
- `frontend/src/app/AppLayout.tsx` — общая шапка, NavLink и Outlet.
- `frontend/src/App.tsx` — вложенные маршруты.
- `frontend/src/main.tsx` — единственный BrowserRouter внутри StrictMode.
- `docs/progress.md` — результаты этапов и проверок.
- `docs/lab2-defense.md` — сценарий демонстрации и ответы для защиты.

## Повторение проверки

1. Откройте `/`: появится коллекция из пяти книг.
2. Откройте b1 и b2; сравните автора, статус, оценку и заметку.
3. Вставьте `/books/b2` в новую вкладку, обновите страницу; запись должна сохраниться.
4. Откройте создание, неизвестный путь и отсутствующую книгу.
5. Проверьте возврат к списку, назад/вперёд и переходы Tab/Enter.
6. При ширине 360 px убедитесь, что длинное название b5 переносится без горизонтальной прокрутки.
7. Временно замените массив в `data/books.ts` на `[]`: появится «Книг пока нет».
   После проверки обязательно восстановите пять записей.
8. В Network выберите Document: внутренние переходы не должны загружать новый HTML.
   Проверьте отсутствие ошибок и предупреждений о key в консоли.
9. Выполните сборку и откройте `/books/b2` напрямую в preview.
10. В чистой копии репозитория повторите `cd frontend`, `npm ci`, `npm run build`.

`node_modules`, `dist`, локальные переменные среды и временные проверки исключены из Git.
