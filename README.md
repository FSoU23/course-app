# Личная библиотека — книги, статусы чтения и заметки

Веб-приложение для учета личной библиотеки, отслеживания статусов чтения (запланировано, читаю, прочитано) и ведения личных заметок к произведениям.

## Информация о проекте
- **Автор:** Каташинский А.В.
- **Группа:** 24ПИ2
- **Основной сценарий:** Просмотр коллекции книг, фильтрация по статусам чтения, добавление/редактирование карточек книг, сохранение личных заметок и оценок.

## Стек технологий и среда

- **Стилизация:** CSS
- **Версия Node.js:** 22.20.0

## Контрольные вопросы и ответы (Защита ЛР 1)

### 1. Как связаны index.html, main.tsx и App.tsx?
- **index.html** — главная точка входа браузера; содержит контейнер `<div id="root"></div>` и разметку страницы, где подключается скрипт `/src/main.tsx`.
- **main.tsx** — точка входа React-приложения; находит DOM-элемент `#root` и с помощью метода `createRoot` монтирует в него базовый компонент `<App/>`.
- **App.tsx** — главный React-компонент, который описывает структуру, логику и пользовательский интерфейс стартового экрана.

### 2. Чем JSX отличается от обычной HTML-разметки?
- **JSX** — синтаксическое расширение JavaScript. В отличие от HTML:
  - Позволяет внедрять любые JS-выражения прямо в разметку через фигурные скобки `{}`.
  - Использует наименования атрибутов в стиле camelCase (например, `className` вместо `class`, `htmlFor` вместо `for`).
  - Требует обязательного закрытия всех элементов, включая одиночные теги (например, `<br />`, `<img />`).

### 3. Какую ошибку в вашем проекте обнаруживает TypeScript?
- **TypeScript** выполняет статическую проверку типов до запуска кода. Если переменной `appTitle` с явным типом `string` присвоить число (`const appTitle: string = 123`), компилятор `tsc` зафиксирует ошибку несовместимости типов и заблокирует сборку проекта (`npm run build`).

### 4. Чем отличаются dev, build и preview?
- **npm run dev** — запускает локальный сервер разработки с быстрой перезагрузкой изменений в реальном времени (Hot Module Replacement).
- **npm run build** — компилирует TypeScript в JavaScript и собирает оптимизированный продакшн-код в папку `dist/`.
- **npm run preview** — поднимает локальный веб-сервер для проверки собранных файлов из папки `dist/` перед деплоем.

### 5. Зачем нужен package-lock.json и почему node_modules не хранится в Git?
- **package-lock.json** — фиксирует точные версии всех установленных пакетов и их зависимостей. Это гарантирует одинаковую сборку на любом ПК при установке через `npm ci`.
- **node_modules** — не хранится в Git из-за большого размера и динамической природы. Она исключается через `.gitignore` и за секунды восстанавливается с помощью команды `npm ci`.

### 6. Чем отличаются commit и push?
- **git commit** — сохраняет подготовленные изменения как новую точечную запись (снимок) в истории **локального** репозитория.
- **git push** — выгружает накопленные локальные коммиты на **удалённый** сервер (например, GitHub).
